Teaching tip: Start with the business question, not the visual. Ask learners what they want the audience to notice first, then choose the chart that makes that answer easiest to see.

Pick by question, not by looks

The fastest way to choose a chart is to finish this sentence: "I want to show how X ___."

...compares across categories
Use a Bar or Column chart
...changes over time
Use a Line chart
...makes up a whole
Use a Donut / Treemap
...relates two measures
Use a Scatter chart
...narrows through stages
Use a Funnel chart
...builds up/down to a total
Use a Waterfall chart
...is one headline number
Use a Card / KPI
...needs exact figures read
Use a Table / Matrix
01

Comparison charts

Answer "which is bigger?" across categories like courses, branches, or trainers.

Clustered Column Chart

Vertical bars, one per category. The default choice for comparing discrete groups side by side.

Use forComparing enrollments across 4–8 courses at a glance.
Avoid whenYou have 15+ categories — labels collide and it turns unreadable.

Bar Chart (horizontal)

Same idea as a column chart, rotated 90°. Category names run along the left instead of the bottom.

Use forLong category labels ("Python & Data Analytics Trainer Batch") that would wrap awkwardly on a column chart.
Column vs. Bar: identical data, different orientation. Column reads better for time-like sequences; Bar reads better for long text labels or ranked lists.

Stacked Column Chart

Bars split into colored segments so you see the total and its breakdown in one shape.

Use forTotal monthly revenue, broken into course categories, without a second chart.
Avoid whenYou need to compare the middle segments precisely — only the bottom segment and the total are easy to read exactly.
02

Trend charts

Answer "what happened over time?" — months, weeks, batches, semesters.

Line Chart

Points connected by a line, tracing direction and rate of change across a continuous axis.

Use forMonthly enrollment trend across a 6-month batch cycle.

Area Chart

A line chart with the space beneath it filled in, which emphasizes volume and magnitude, not just direction.

Use forShowing cumulative revenue building up over the year — the filled area reads as "accumulated mass."
Avoid whenComparing several overlapping series — the fills obscure each other. Use a Line chart instead.
Line vs. Area: Line is precise and layers well with multiple series; Area is bolder and better for one hero metric or a stacked total.

Line and Clustered Column (Combo)

Bars on one axis, a line on a second axis — for two measures on different scales, shown together.

Use forEnrollments (bars) against fee revenue (line) across the same months, when the two numbers live on different scales.

Ribbon Chart

Like a stacked column, but ranks segments each period and shows crossovers with twisting ribbons between bars.

Use forWhich course had the highest enrollment each month, and exactly when one course overtakes another.
03

Part-to-whole charts

Answer "what share does each piece hold?"

Pie Chart

A circle sliced by proportion. Best kept to 2–5 slices — beyond that, the angles get hard to compare.

Use forShare of students across just 3 course categories: Web Dev, Data Analytics, Office Tools.

Donut Chart

A pie chart with the center removed — same proportions, but the hole is a natural spot for a total or icon.

Use forSame course-share data, with total enrolled students displayed in the center.
Pie vs. Donut: functionally identical. Donut is preferred in dashboards because the center can host a KPI number; pie feels more "complete" for a single standalone stat.

Treemap

Nested rectangles sized by value — handles far more categories than a pie chart without losing legibility.

Use forRevenue by course when you have 10+ courses, including small ones a pie chart would squash into slivers.
04

Relationship & distribution

Answer "how do two measures move together?" or "how spread out is this data?"

Scatter Chart

Each point plots two measures at once — reveals correlation, clusters, and outliers a bar chart can't show.

Use forStudy hours vs. exam score per student, to check whether more practice actually correlates with results.

Bubble Chart

A scatter chart with a third measure encoded as bubble size — three variables in one view.

Use forFee (x) vs. satisfaction rating (y) vs. batch size (bubble size) per course, all at once.
Avoid whenBubbles overlap heavily — size becomes hard to judge accurately past 15-20 points.
Scatter vs. Bubble: Scatter compares 2 measures; Bubble adds a 3rd via size. Add a 3rd only if it genuinely changes the story — otherwise it's noise.
05

Flow & single-value visuals

Answer "where did the number go?" or "what's the headline figure right now?"

Waterfall Chart

Floating bars show how a starting value is pushed up or down by a sequence of gains and losses to reach a final total.

Use forRevenue bridge: last year's total, plus new enrollments, minus dropouts, minus refunds, equals this year's total.

Funnel Chart

Bars shrink from top to bottom, showing how a group narrows through sequential stages.

Use forInquiries → Demo attended → Enrolled → Completed course, to spot the biggest drop-off stage.

Gauge Chart

A speedometer-style arc showing one value against a target or range — instantly readable as "on track" or not.

Use forEnrollment target progress: 78 of 100 seats filled this batch.
Avoid whenYou need to show trend or comparison — a gauge only ever shows one moment, one number.

Card / KPI Visual

One number, as large as possible. No axes, no categories — just the headline figure, sometimes with a trend arrow.

Use for"Total students enrolled this month" pinned at the top of a dashboard.

Table / Matrix

A. Comparison, Trend & Change Visuals
01
Comparison

Stacked Bar Chart

What it is: Compare category totals while showing how each total is split into subcategories.

When to use: Use when you need both the overall size of each category and the contribution of several components.

Example: Example: Total sales by region, split by product category.

Best for: category comparison + composition.
02
Comparison

Stacked Column Chart

What it is: Vertical version of a stacked bar chart; each column shows a total and its internal composition.

When to use: Use when categories are limited and you want to compare totals across periods or groups.

Example: Example: Monthly revenue split by sales channel.

Best for: time/category comparison + composition.
03
Comparison

Clustered Bar Chart

What it is: Places bars side-by-side so multiple measures or groups can be compared directly.

When to use: Use when precise comparison between categories is more important than showing a total.

Example: Example: Sales of Product A, B and C across regions.

Best for: ranking and side-by-side comparison.
04
Comparison

Clustered Column Chart

What it is: Uses vertical columns to compare separate series across categories.

When to use: Use when category order or time sequence is important and labels are manageable.

Example: Example: Actual vs Target sales by month.

Best for: direct comparison.
05
Composition

100% Stacked Bar Chart

What it is: Normalizes every bar to 100%, emphasizing percentage contribution rather than absolute size.

When to use: Use when you want to compare mix or share across categories with different totals.

Example: Example: Percentage of customers by segment in each region.

Best for: proportional comparison.
06
Composition

100% Stacked Column Chart

What it is: Normalizes each column to 100% so the visual focuses on relative contribution.

When to use: Use when comparing percentage composition across periods or categories.

Example: Example: Product-category share of sales by year.

Best for: percentage mix over time.
07
Trend

Line Chart

What it is: Connects values across an ordered axis to make movement, peaks and dips easy to see.

When to use: Use for time-series data and continuous trends.

Example: Example: Monthly sales, daily website visits or temperature.

Best for: trends and patterns.
08
Trend

Area Chart

What it is: A line chart with the area filled below it, making the magnitude of change more visually prominent.

When to use: Use when the size of the movement matters in addition to the trend.

Example: Example: Revenue growth over 12 months.

Best for: trend + magnitude.
09
Trend + Composition

Stacked Area Chart

What it is: Shows how several components contribute to a changing total over time.

When to use: Use when both total movement and changing component contributions matter.

Example: Example: Revenue by product category over time.

Best for: cumulative trends and composition.
10
Combo

Line & Stacked Column Chart

What it is: Combines stacked columns with a line so totals/components and a separate trend measure can be viewed together.

When to use: Use when two related measures tell different parts of the same story.

Example: Example: Sales by channel with profit margin as the line.

Best for: mixed measures.
11
Combo

Line & Clustered Column Chart

What it is: Combines grouped columns with a line for comparing categories while tracking another measure.

When to use: Use when two measures have different scales or roles.

Example: Example: Units sold as columns and average price as a line.

Best for: comparison + trend.
12
Ranking

Ribbon Chart

What it is: Shows how category ranking changes across periods, with ribbons moving as ranks change.

When to use: Use when the important question is who moved up or down in rank.

Example: Example: Top product categories by quarter.

Best for: rank changes.
13
Change Analysis

Waterfall Chart

What it is: Starts with an initial value and shows positive and negative contributions until the final result.

When to use: Use to explain what caused a total to increase or decrease.

Example: Example: Opening profit → revenue gains → costs → closing profit.

Best for: bridges and variance analysis.
14
Process

Funnel Chart

What it is: Displays values across sequential stages, normally narrowing as records progress through a process.

When to use: Use for pipelines, conversion and stage-by-stage drop-off.

Example: Example: Leads → Qualified → Proposal → Won.

Best for: process conversion.
B. Relationship, Composition, Maps, KPI & Detail Visuals
15
Relationship

Scatter Chart

What it is: Plots individual observations against two numeric measures to reveal correlation, clusters and outliers.

When to use: Use when you want to understand whether two measures move together.

Example: Example: Sales vs profit for individual products.

Best for: correlation and outliers.
16
Part-to-Whole

Pie Chart

What it is: Shows how categories contribute to one total using slices of a circle.

When to use: Use only when there are a small number of categories and the share is the main message.

Example: Example: Sales share by channel.

Best for: simple composition.
17
Part-to-Whole

Donut Chart

What it is: A pie chart with a center opening that can provide room for a total or label.

When to use: Use for a compact part-to-whole view with a prominent total.

Example: Example: Completed vs remaining tasks.

Best for: simple share + total.
18
Hierarchy + Composition

Treemap

What it is: Uses nested rectangles where size represents value and grouping represents hierarchy.

When to use: Use when many categories or hierarchical parts must fit into limited space.

Example: Example: Sales by category → subcategory → product.

Best for: hierarchy and composition.
19
Geographic Analysis

Map

What it is: Places data points on a geographic map using location fields.

When to use: Use when location is an important part of the business question.

Example: Example: Store sales by city.

Best for: geographic patterns.
20
Geographic Analysis

Filled Map

What it is: Colors geographic regions according to a measure, creating a shaded regional map.

When to use: Use when the comparison is between areas such as states, districts or countries.

Example: Example: Population by state.

Best for: regional intensity.
21
Geographic Analysis

Shape Map

What it is: Uses custom geographic shapes to compare values across defined regions.

When to use: Use for non-standard regions, territories or specialized boundaries.

Example: Example: Sales by business territory.

Best for: custom geographic regions.
22
Advanced Mapping

Azure Maps

What it is: Provides richer geospatial mapping capabilities for location-based analysis.

When to use: Use when you need advanced geographic visualization, layers or spatial context.

Example: Example: Delivery locations, stores, routes or density patterns.

Best for: advanced geospatial analysis.
23
Goal / Progress

Gauge

What it is: Shows one value against a target or range using a radial meter.

When to use: Use when the audience needs a quick status check against a goal.

Example: Example: Current sales vs monthly target.

Best for: one KPI vs target.
24
Single Value

Card

What it is: Highlights one important number in a large, easy-to-read format.

When to use: Use when one metric deserves immediate attention.

Example: Example: Total Revenue, Total Customers or Net Profit.

Best for: executive summary KPIs.
25
Goal / Performance

KPI

What it is: Communicates progress toward a target and can include direction, trend and status.

When to use: Use when the question is whether performance is ahead or behind a goal.

Example: Example: Actual sales vs target with monthly trend.

Best for: goal tracking.
26
Filtering

Slicer

What it is: Provides an interactive on-canvas control for filtering the report.

When to use: Use when report viewers need to choose categories, dates or ranges themselves.

Example: Example: Filter dashboard by Year, Region or Product.

Best for: interactive filtering.
27
Detailed Data

Table

What it is: Displays exact values in rows and columns for detailed inspection.

When to use: Use when users need to read or compare individual records and measures.

Example: Example: Customer, Order Date, Product and Sales.

Best for: detail and audit.
28
Hierarchical Detail

Matrix

What it is: Displays summarized data in a pivot-style layout with rows, columns, subtotals and drill-down.

When to use: Use when multiple dimensions and hierarchical analysis are required.

Example: Example: Region → Country → City with years across columns.

Best for: multidimensional reporting.

Quick selection rule: Start with the business question, not the chart style. “How do categories compare?” → bar/column. “How is it changing over time?” → line/area. “What makes up the total?” → stacked/pie/donut/treemap. “What is related to what?” → scatter. “Where is it happening?” → map. “Are we meeting a goal?” → KPI/gauge/card. “Why did it happen?” → Key Influencers/Decomposition Tree/assisted analysis.
